## 1. Привычки и серии (Streaks)

### 1.1 — Forgiving Streak (Мягкая серия)
**Почему цепляет:** Классический streak ломается при одном пропуске → пользователь бросает всё. «Мягкая серия» по принципу Джеймса Клира «Never miss twice» даёт 1 день grace period. Пропустил один день — серия «на паузе» с предупреждением, пропустил два подряд — сброс. Исторический рекорд серии сохраняется навсегда.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  🔥 Серия: 47 дней                       │
│  ████████████████████████░░  (47/50)      │
│  ⚡ До награды «Полтинник»: 3 дня         │
│                                          │
│  ⚠️ Вчера пропущено — серия на паузе!     │
│  [Выполнить мини-версию] чтобы сохранить  │
└──────────────────────────────────────────┘
```
- Прогресс-бар с milestone-маркерами (7, 14, 30, 50, 100 дней)
- Оранжевая пульсация на иконке при «паузе»
- Попап при угрозе сброса: «Сделай хотя бы 1 из 5 привычек сегодня»

### 1.2 — GitHub-style Contribution Heatmap
**Почему цепляет:** Визуальный паттерн 365 дней — видишь пробелы, хочешь заполнить. Работает как «виртуальная витрина» достижений.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  📅 2024                                 │
│  Пн ░░██░███████░██████████░████░██████  │
│  Вт ░████████████░█████████████████████  │
│  Ср ██████████████████████████████░░███  │
│  ...                                     │
│  Цвета: ░ пусто  █ 1-2  ██ 3-4  ███ 5+  │
│  💡 Лучший месяц: Март (96%)             │
└──────────────────────────────────────────┘
```
- Тап по клетке → попап с деталями дня
- Цветовая кодировка по интенсивности (0–5 привычек = оттенки зелёного/синего)
- Статистика consistency rate внизу

### 1.3 — Micro Habits (Мини-привычки)
**Почему цепляет:** Барьер входа снижен до минимума. «Прочитать 1 страницу» вместо «Читать 30 минут». Человек начинает и часто делает больше.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  📖 Чтение                               │
│  Мини: 1 страница │ Полная: 30 мин       │
│  [✓ Мини] [✓✓ Полная]                    │
│  XP: +5 / +25                            │
└──────────────────────────────────────────┘
```

### 1.4 — Habit Stacking Chains
**Почему цепляет:** Привычки привязаны к якорю — «После утреннего кофе → 5 минут растяжки → записать 3 благодарности». Цепочка визуализируется как pipeline.

**UI для PWA:**
```
┌─────────────────────────────────────────┐
│  ⛓ Утренняя цепочка                    │
│  ☕ Кофе ──→ 🧘 Растяжка ──→ 📝 3 благ. │
│  [✓]         [✓]             [ ]        │
│  2/3 выполнено                          │
└─────────────────────────────────────────┘
```

## 2. Финансы и бюджет

### 2.1 — Envelope Budgeting (Конверты)
**Почему цепляет:** Визуальная метафора физических конвертов с деньгами. Каждая категория расходов — конверт, который «пустеет». Работает как YNAB, но проще.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  💰 Бюджет июля           Остаток: 34 200₽│
│                                          │
│  🍔 Еда        ████████░░  8 200 / 12 000│
│  🚗 Транспорт  █████░░░░░  3 100 / 6 000 │
│  🎮 Развлечения██████████  5 000 / 5 000 ⚠│
│  👕 Одежда     ██░░░░░░░░  2 400 / 10 000│
│  💊 Здоровье   ░░░░░░░░░░  0 / 5 000     │
│                                          │
│  [+ Добавить расход]                      │
└──────────────────────────────────────────┘
```
- Конверт краснеет при >80% расхода
- Swipe-жест для быстрого добавления траты
- Автосуммирование по дням/неделям/месяцам

### 2.2 — Income vs Expenses Flow (Санкей-подобная визуализация)
**Почему цепляет:** Видно, куда утекают деньги. Эффект «вот блин» заставляет менять поведение.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  📊 Денежный поток — Июль                │
│                                          │
│  ДОХОД ═══════════╗                      │
│  Ozon   42 000 ═══╬══► Еда     12 000   │
│  Фриланс 15 000 ═╣ ══► Аренда  18 000   │
│                   ╚══► Транспорт 6 000   │
│                    ══► Накопления 21 000  │
│                                          │
│  💡 Норма накоплений: 37% (+5% vs июнь)  │
└──────────────────────────────────────────┘
```

### 2.3 — Daily Spending Pulse
**Почему цепляет:** Одно число: «Сегодня можно потратить 1 430₽». Обновляется в реальном времени.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│         Сегодня можно потратить:          │
│              💵 1 430 ₽                  │
│         ░░░░░░░░████████ 12 дней до ЗП    │
│   Вчера потрачено: 890₽ (ниже лимита ✓)  │
└──────────────────────────────────────────┘
```

## 3. Здоровье и wellness

### 3.1 — Water Tracker (Вода)
**Почему цепляет:** Визуальная метафора наполняющегося стакана/бутылки. Тап = +250мл. Микро-анимация «буль-буль». Напоминания каждые 2 часа.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  💧 Вода сегодня                          │
│                                          │
│     ┌─────┐                              │
│     │~~~~~│  2000 мл                     │
│     │~~~~~│                              │
│     │     │  ← цель: 2500 мл            │
│     │     │                              │
│     └─────┘  80%                         │
│                                          │
│  [+250мл] [+500мл] [☕ Кофе]             │
│  ⏰ Следующее напоминание: 14:30          │
└──────────────────────────────────────────┘
```
- Анимация волн в «стакане» (CSS wave animation)
- Цвет воды меняется от бледного к насыщенному
- «Кофе» считается за 0.5x (обезвоживает)

### 3.2 — Sleep Score
**Почему цепляет:** Одно число 0-100 вместо сложных графиков. Ввод за 5 секунд: время лёг → время встал → самочувствие (1-5 emoji).

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  😴 Сон                   Score: 78/100  │
│                                          │
│  🌙 23:30 ──────────── ☀️ 07:15          │
│            8ч 45мин                      │
│                                          │
│  Самочувствие: 😊 Хорошо                 │
│  Тренд: ↑ +5 за неделю                   │
│                                          │
│  📈 Ср. за 30 дней: 72                    │
│  🏆 Лучший: 94 (12 июля)                │
└──────────────────────────────────────────┘
```

### 3.3 — Mood Tracker (Настроение)
**Почему цепляет:** 5 emoji = 2 секунды на ввод. Корреляция настроения с привычками открывает инсайты: «В дни с пробежкой твоё настроение на 40% выше».

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  Как ты сейчас?                           │
│                                          │
│  😫  😕  😐  🙂  😄                      │
│                                          │
│  Что повлияло? (мульти-выбор):            │
│  [Работа] [Сон] [Спорт] [Люди]           │
│  [Погода] [Еда] [+ своё]                 │
│                                          │
│  📝 Заметка (опционально): ___________    │
└──────────────────────────────────────────┘
```
- Календарь настроений: месяц из emoji
- Корреляционный виджет: «Спорт → +35% к настроению»
- 2-3 чек-ина в день (утро/день/вечер)

### 3.4 — Body Dashboard
**Почему цепляет:** Вес, шаги, калории — на одном экране. Тренд-линии показывают прогресс.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
```

## 4. Цели и OKR

### 4.1 — 90-Day Quests (Квартальные квесты)
**Почему цепляет:** Год — слишком далеко, неделя — слишком мелко. 90 дней = идеальный горизонт. Цель разбивается на 12 недельных milestone'ов.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  🎯 Q3 2024: Заработать 200 000₽         │
│                                          │
│  Прогресс: 142 000₽  ██████████░░░ 71%  │
│  Осталось: 58 000₽ за 34 дня             │
│  Темп: нужно 1 706₽/день (сейчас 1 580)  │
│                                          │
│  Недельные чекпоинты:                     │
│  ✅ Нед 1-8: выполнены                   │
│  🔶 Нед 9: 12 400 / 15 000 (в процессе)  │
│  ⬜ Нед 10-12: впереди                   │
│                                          │
│  [Обновить прогресс]                      │
└──────────────────────────────────────────┘
```

### 4.2 — Life Areas Wheel (Колесо жизни)
**Почему цепляет:** Радарная диаграмма из 8 областей жизни. Визуальный перекос мотивирует подтянуть слабые зоны.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  ⭕ Колесо баланса                        │
│                                          │
│         Карьера 8                         │
│      Финансы 7    Здоровье 6             │
│    Отношения 4      Рост 9              │
│      Друзья 5     Отдых 3               │
│         Духовное 5                       │
│                                          │
│  ⚠️ Слабые зоны: Отдых (3), Отношения (4)│
│  📋 Рекомендация: добавь 2 привычки       │
│     на отдых и общение                    │
└──────────────────────────────────────────┘
```
- Radar chart (canvas/SVG) с 8 осями
- Обновление раз в неделю (воскресный ритуал)
- Бонусный XP за улучшение слабой зоны

### 4.3 — North Star Metric
**Почему цепляет:** Одна главная метрика на главном экране. Всё остальное — подчинено ей.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  ⭐ Моя North Star: 200 000₽ за квартал  │
│  ═══════════════════░░░░░░  71%          │
│  142 000₽ из 200 000₽                    │

└──────────────────────────────────────────┘
```

## 6. Акции и крипто виджеты

### 6.1 — Portfolio Ticker (Тикер портфеля)
**Почему цепляет:** «Бегущая строка» с ценами — как на Bloomberg-терминале. Визуал профессионала. Обновляется в реальном времени.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
```

- Горизонтальный скролл / marquee эффект
- Зелёный = рост, красный = падение
- Тап → модальное окно с графиком за 24ч

**Почему цепляет:** Каждый актив — карточка с мини-спарклайном. Видно P&L (прибыль/убыток) в рублях.

## 7. Аналитика продуктивности

### 7.1 — Deep Work Timer (Таймер глубокой работы)
**Почему цепляет:** Pomodoro + трекинг фокус-часов. Видно, сколько «чистых» часов работы за день/неделю. Конкурируешь с собой.

**UI для PWA:**
```
┌──────────────────────────────────────────┐
│  🎯 Deep Work                            │
│                                          │
│         25:00                            │
│     ╭──────────────╮                     │
│     │    18:42     │                     │
│     │   осталось   │                     │
│     ╰──────────────╯                     │
│                                          │
│  Сессия 3/4      Задача: Маршруты        │
│  [⏸ Пауза]  [⏭ Пропустить]              │
│                                          │
│  📊 Сегодня: 2ч 15мин deep work          │
│  📈 Эта неделя: 14.5ч (цель: 20ч)       │
└──────────────────────────────────────────┘
```

## 💡 Ключевые инсайты из исследования

### Почему люди ОТКРЫВАЮТ трекер каждый день:

1. **Страх потери (Loss Aversion)** — серия горит, питомец голодает, дерево сохнет. Потеря мотивирует в 2x сильнее награды.
2. **Мгновенный фидбек** — XP, звук, анимация, confetti СРАЗУ при выполнении. Задержка >2 секунд убивает дофамин.
3. **Variable Reward** — непредсказуемые награды (случайный бонус XP, скрытые ачивки) запускают дофаминовый цикл.
4. **Social Proof** — видеть, что ты не один (лидерборд, даже если конкуренция с собой вчерашним).
5. **Minimal Input, Maximum Insight** — ввод данных за 5-10 секунд, но аналитика вытаскивает скрытые паттерны.
6. **Ритуал** — приложение привязано к времени дня (утренняя цитата, вечерний дневник, ночной sleep log).
7. **Прогресс виден** — heatmaps, прогресс-бары, уровни, радарные диаграммы. Абстрактный прогресс невидим → демотивирует.

### Ключевые принципы дизайна:
- **Compassion > Punishment** — NeuroHabit и Taskoria доказали: не наказывай за пропуск, мягко напоминай
- **ADHD-friendly** — минимальные микро-праздники, информация по запросу, не перегружай
- **One number** — для каждой области дай ОДНУ метрику (Sleep Score 78, Productivity 82, Mood 🙂)
- **2-second rule** — любой ввод должен занимать < 2 секунд (1 тап на emoji, 1 тап +250мл воды)
